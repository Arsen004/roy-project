# Roy Social Network

Современная социальная сеть с дизайном в стиле Apple Human Interface и полной интеграцией API.

## 🚀 Быстрый старт

### ⚠️ Важно: Устранение конфликта зависимостей

Если вы получили ошибку `ERESOLVE unable to resolve dependency tree`, выполните эти команды:

```bash
# 1. Очистите все зависимости
rm -rf node_modules package-lock.json

# 2. Очистите npm кеш
npm cache clean --force

# 3. Установите зависимости с legacy-peer-deps
npm install --legacy-peer-deps
```

### Стандартная установка

```bash
# Установить зависимости
npm install

# Запуск в режиме разработки
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173

### Альтернативные методы установки

Если npm не работает, попробуйте:

```bash
# Yarn
yarn install && yarn dev

# pnpm  
pnpm install && pnpm dev
```

## ✨ Возможности

- **Современный UI**: Дизайн в стиле Apple Human Interface
- **Полная функциональность**: Посты, комментарии, лайки, подписки
- **Real-time обновления**: Живые уведомления и обновления
- **Темная/светлая тема**: Автоматическое переключение тем
- **Мобильная адаптация**: Полностью адаптивный дизайн
- **API документация**: Встроенная документация со всеми endpoints

## 🛠️ Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Tailwind CSS v4** - Стили с Apple-подобными токенами
- **Motion** - Анимации (бывший Framer Motion)  
- **Vite** - Сборщик
- **Radix UI** - Headless компоненты
- **Lucide React** - Иконки

## 📱 Экраны

- **Auth**: Логин и регистрация
- **Feed**: Лента постов с фильтрами
- **Thread**: Просмотр поста с комментариями
- **Search**: Поиск пользователей и постов
- **Profile**: Профиль пользователя
- **Settings**: Настройки аккаунта
- **Notifications**: Уведомления
- **Chat**: Система сообщений
- **API Docs**: Полная документация API

## 🔌 API Integration

Все экраны содержат блоки "API Notes" с HTTP методами и маршрутами:

- **95+ endpoints** для всех социальных функций
- **Real-time WebSocket** соединения
- **JWT аутентификация**
- **Пагинация и rate limiting**
- **Примеры интеграции** с кодом

## 🎨 Дизайн система

- **Цветовая схема**: Apple Human Interface
- **Типографика**: SF Pro Display / Inter
- **Сетка**: 8pt система с максимальной шириной 1100px
- **Анимации**: Плавные переходы и микроанимации
- **Компоненты**: Полная библиотека атомов, молекул и организмов

## 🔧 Устранение неполадок

### Конфликт зависимостей (ERESOLVE)
```bash
npm install --legacy-peer-deps
```

### Проблемы с портом
```bash
npm run dev -- --port 3000
```

### Проблемы с Node.js версией
Убедитесь, что используете Node.js 18+ :
```bash
node --version  # должно быть >= 18.0.0
```
